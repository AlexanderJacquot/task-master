# task-master 0.11.0

## Lineage

- **Lanes.** The new **Arrange** choice lays the canvas out freely (as before), in
  **lanes by epic** or in **lanes by project**. Lanes follow your epic or project order,
  with "No epic" / "No project" last, and active epics get a lane even while empty.
  Prerequisites stay left of their dependents across lanes. Inside a lane, place cards
  where you like. **Drop a card into another lane to give it that epic or project**
  (undoable). Lane headers stay at the left edge as you pan, and lanes collapse.
- **Pins.** Hover a card's top-right corner and click the pin. A pinned card can't be
  dragged or nudged, and **Auto arrange** leaves it in place and moves other cards off it.
- **Remove a link** with the × in the middle of an arrow. It appears when you hover a
  card or an arrow, and on the selected card's arrows.
- **Epic on cards**, in the epic's color (hidden in epic lanes, where the lane names it).
- **Link without searching.** With a card selected, the side panel lists its epic's
  tasks, then its project's, with the Prereq / Dependent / Parent / Subtask buttons. With
  none selected, it lists the tasks your filters match that the canvas leaves out. The
  plus button on a card suggests open tasks of the same epic or project before you type.
- **Filters.** The Epic and Tags filters take several values and list **No epic** and
  **No tag**, like the other views. With a project picked, the Epic filter now also lists
  epics without a project (it could show only "All epics" before).

## Agents

- Claude sessions in WSL find Claude Code when it's installed in `~/.local/bin` (or
  anywhere your login shell's PATH reaches). They failed with `execvpe(claude) failed`.

## Settings and look

- The sync frequency moved from Data and backups to **Sync**.
- Settings categories use the app's own icons.
- List rows no longer show a sliver of the hidden "Due…" button.

## Open source

task-master is now free software under the **GNU Affero General Public License v3.0 or
later**. Settings → About links to the license and the source code. The README has a
new look, screenshots and a quickstart.

## Server and upgrade

No database changes: schema stays at **12**, so 0.8.0 to 0.11.0 desktops and servers sync
with each other. The server image `ghcr.io/alexanderjacquot/task-master-server:v0.11.0`
is published as usual; upgrading the server is optional.

Installed desktops can update from **Settings → About → Check for updates**.
New installations use the Windows setup executable, macOS DMG, or Linux
AppImage/DEB/RPM. Updates are signed; installers are not platform code-signed.

Lineage layouts (positions, pins, lanes) stay on each computer; links sync as before.
