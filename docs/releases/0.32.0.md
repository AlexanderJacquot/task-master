# task-master 0.32.0

Scribe: voices named from the meeting's participants, and a meeting handed to Claude for its
summary and follow-up tasks.

**Database schema 23**, as in 0.29 to 0.31: no migration. Keep your sync server on the same
version as your desktops all the same.

## Scribe

- **Name voices from the participants.** A voice's name is now a picklist of the
  meeting's participants. "Someone else…" types a new name, which then joins the
  participants; a meeting with nobody listed keeps the text field. Picking a name another
  voice already has merges the two voices.
- **The last voice names itself.** When one unnamed voice and one unused participant are
  left, the app gives that voice the name as you name the others, and otherwise offers it
  as a one-click suggestion. Names left on merged voices do not count.
- **Summary and Send to Claude.** The meeting page shows the meeting's summary. Send to
  Claude opens the Send to agent dialog with instructions you can edit: the agent reads
  the transcript, writes the summary and creates your tasks in the project. Its follow-up
  task ("Follow up: <title>") is created only when you press Start, under the meeting's
  task; sending again nests a new follow-up under the previous one.

## MCP

- `get_meeting` takes `transcript: true`, and `set_meeting_summary` writes a meeting's
  summary. Both are allowed only in a session started from that meeting's task, or with
  editing the user's tasks turned on.

## Project

- The GitHub repository restarted from a single commit, and the Forgejo copy now only
  mirrors it (ADR 041). Releases before 0.32.0 are no longer listed on GitHub; installed
  apps update from this release as before.
