# task-master 0.7.0

## Agent sessions

- Send a task to an agent with its project folder, task context and related work.
  Follow progress in the task panel or Agents page, send follow-ups, and resume the
  conversation in a terminal. Claude Code must be installed and signed in separately.
- The desktop installers bundle the task-master MCP server. Agents can read task
  context, create their own tasks and subtasks, record notes, and summarize their work.
- Finished agent work moves your task to **Review**. You decide when to mark it Done;
  agents can complete their own tasks but cannot close yours.
- Agent tasks and subtasks have clearer indicators, and agent-owned work is kept
  separate from your normal task views.
- Running sessions can be watched in a terminal on Linux, macOS and WSL. Terminal
  sessions close after completion on supported runtimes, and sessions started from an
  agent-launched app no longer inherit the parent session's identity.

## Desktop improvements

- Freeform Lineage canvas for arranging related tasks and dependencies.
- Medieval icons, updated app artwork, a tarot-inspired Today sun and a redrawn quill.
- Settings grouped into General, Workflow, Shortcuts, Sync, Calendar, Agents,
  Data and backups, and About, with direct links to each category.
- Sidebar navigation restored to rows, with a larger square shortcuts button.
- Clearer subtask badges and fixes for clipped board selection outlines.
- Calendar popup refinements and published project/privacy/terms pages for Google
  OAuth setup.

## Server and upgrade

**Upgrade the sync server and every desktop to 0.7.0 together.** The shared database
schema advances to **11**, adding agent sessions, task ownership and the Review
status. Existing databases migrate automatically, with a backup before migration;
sync requires matching schema versions.

Server image: `ghcr.io/alexanderjacquot/task-master-server:v0.7.0` (also `latest`).
This release publishes the image; deployment remains a separate step.

Installed desktops can update from **Settings → About → Check for updates**.
New installations use the Windows setup executable, macOS DMG, or Linux
AppImage/DEB/RPM. Updates are signed; installers are not platform code-signed.

Native Windows does not support watching a running session through the POSIX log
viewer or automatic terminal shutdown; use the WSL runtime for those features.
