# task-master 0.30.1

A fix for quick capture on Windows.

**Database schema 23**, as in 0.29 and 0.30: no migration. Keep your sync server on the
same version as your desktops all the same.

## Quick capture

- **Shift+Enter opens the editor again on Windows.** Since 0.26.0, Shift+Enter in the
  quick-capture window (Ctrl+Shift+Space) saved the task and closed the window, like a
  plain Enter, instead of growing it into the task editor. Growing the window briefly took
  focus from the page on Windows, and the window closed on that blur. It now stays open
  while it grows.

## For contributors

- The notes tree's drag handlers name their event types, so `pnpm typecheck` passes again.
- The Windows fix comes from reading Tauri's WebView2 focus handling; it was tested with a
  fake window in `captureWindow.test.tsx`, not yet on a Windows machine.
