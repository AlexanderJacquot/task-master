# task-master 0.16.0

## Agents

- **Agent runs time the task.** Sending a task to an agent (Send to agent, a follow-up, or
  Resume) starts the work timer on it. When that session finishes, fails, is stopped or is
  interrupted, the timer stops and logs the run on the calendar. Continuing in a terminal
  keeps it running. A timer you start by hand is not stopped by a session.
- **Agents page: cost, time and limits.** Filter by project and by period (Today, This week,
  This month, All time). Tiles show spend, agent time, sessions and turns, with a table by
  project. Settings → Agents sets spend limits per day, week and month, with a meter showing
  what is left. "Send to agent" asks before you go over a limit.
- **Agent sessions record how long the agent worked**, summed over its runs.

## Tasks

- **Multi-select in list and board.** Ctrl/Cmd+click picks tasks, Shift+click picks a range,
  Ctrl+A picks everything in the view, Esc clears. A bar at the bottom sets status, priority,
  project, epic, due date or tags on all of them, or deletes them. One Ctrl+Z undoes the
  whole change.
- **Properties in one order** in the side panel and on the task page: status, project, epic,
  priority, due, today, estimate, time, tags. Set properties no longer jump ahead of empty ones.
- **Paper sounds** on the parchment theme: a sheet crumples when a task opens, a quill
  scribbles when one is created, and a sheet burns when one is deleted. Turn them off in
  Settings → Appearance. Silent on Dark and Clean.

## Lineage

- **Saved Lineage views.** "Save as view" on the Lineage page saves its filters, focus task
  and card layout as a view under Saved views. Edits are a draft until you save or revert.
- **Drag a card onto the side panel** to link it: the panel offers drop zones for its parent,
  a subtask, a prerequisite and a dependent. A drop that would duplicate a link or create a
  loop is ignored.

## Server and upgrade

**Database change: schema 13** (a new `duration_ms` column on agent sessions, migration 0013).
Desktops and sync servers at 0.16.0 use schema 13 and sync only with each other, so upgrade the
sync server together with the desktops. Earlier versions (schema 12) cannot sync with 0.16.0.
The server image `ghcr.io/alexanderjacquot/task-master-server:v0.16.0` is published with the
release.

Installed desktops can update from **Settings → About → Check for updates**.
New installations use the Windows setup executable, macOS DMG, or Linux
AppImage/DEB/RPM. Updates are signed; installers are not platform code-signed.
