# task-master 0.23.2

The macOS build of 0.23.1 failed, so 0.23.1 reached Windows and Linux only. 0.23.2 is the
same release for every system: Scribe recording and local transcription
([0.23.1 notes](0.23.1.md)).

- macOS: the app now needs macOS 10.15 (Catalina) or later; the transcription engine
  (whisper.cpp) does not build for older versions. Recording the computer's sound still
  needs macOS 14.6.
- Windows and Linux: no change from 0.23.1.

Server image: `ghcr.io/alexanderjacquot/task-master-server:v0.23.2` (same schema 16).
