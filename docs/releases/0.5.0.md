# task-master 0.5.0

Connect devices to a self-hosted task-master server from Settings → Sync. Work offline,
then automatically exchange edits and attachments when the server is reachable.

- Merge local tasks with the server, or back up and replace this device's data.
- Connect with a server URL, bearer token, or OpenID Connect sign-in.
- Resolve concurrent edits automatically per field; deletes stay deleted.
- See pending changes, sync errors and clock warnings; request sync manually.
- Host the sync server with daily local backups and optional S3 backup uploads.
- Move Google Calendar sync between the desktop and server from Settings → Calendar;
  exclusive leases prevent competing runners and existing events are reused.
- Expand quick capture into the task editor with Shift+Enter, and open new tasks
  directly in the side panel with the description ready to edit.
- Updated application artwork and illustrated UI icons.
- View task metrics and stale-task indicators in the dashboard.

Update both desktop and server to 0.5.0. Server setup: [server guide](../server.md).
Existing local databases migrate automatically; local tasks remain available offline.

The HTTP API, CLI and MCP remain future milestones.
