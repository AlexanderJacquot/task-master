# task-master 0.30.0

Add task-master to your own Claude from Settings, assign and mention teammates more easily,
and line returns that show up in rendered notes.

**Database schema 23**, as in 0.29: no migration. Keep your sync server on the same version
as your desktops all the same.

## Settings → MCP

- **A new MCP page in Settings** walks you through adding task-master to the Claude you use
  yourself: Claude Code (also inside WSL on Windows), Claude Desktop (macOS, Windows) and
  claude.ai (through your sync server's `/mcp`). It finds this computer's `task-master-mcp`
  and shows the setup lines with the path already filled in, ready to copy.
- Switches for **user scope** (`--scope user`) and **Let Claude edit my tasks**: when it is
  off, the setup passes `--no-edit-user-tasks`.
- From an AppImage, the page warns that the path only exists while the app runs.
- Docs fix: Settings → Agents → **Let agents edit my tasks** applies to Send to agent
  sessions; the server you add yourself follows only `--no-edit-user-tasks`.

## Team spaces

- **Assignee in the side panel**: team tasks have an Assignee field in the task side panel
  (before, only the full page had it), and the project picker offers only projects of the
  task's own space.
- **New task from the Team page**: each member's column has a "+" for a task assigned to
  them (or unassigned), with a title field and a team project picker.
- **@mention picker**: type `@` in a comment, a task description, a note or meeting notes to
  pick a teammate (arrows, Enter or Tab, Esc). Mentions are highlighted in rendered text.
- **Notices for more mentions**: a teammate newly mentioned in a team task's description, a
  team note or an edited comment now gets a notice in "For you", not only in new comments.
  Mentions in personal tasks and notes are only highlighted: teammates cannot see them.
- New team tasks and projects show as the team's at once instead of briefly as personal.

## Markdown

- **Line returns**: a single line return in a note, task description or agent summary now
  renders as a line break. Code blocks keep their own.

## For contributors

- `scripts/team-sim/run.sh` runs a team server and two member apps (Alice and Bob) on one
  machine to try team spaces without a second computer (docs/server.md, section 7a).
- New Tauri command `mcp_setup`; bindings regenerated. No new dependency.
- Not yet clicked through in the running app: the MCP page, the @mention picker and the
  Team page's new-task field.
