# task-master 0.17.1

0.17.0 was tagged but never published: its release build stopped at a formatting check
(in `progress.md`). 0.17.1 is the same release, with the changes listed in
[the 0.17.0 notes](0.17.0.md): Settings → Files, Claude plan usage and sessions by day on
the Agents page, MCP agent-session filters, a 3-day calendar range, calendar filters that
pick several projects, epics and statuses, Reset view, dragging a multi-selection on the
board, and Lineage lanes for epics in view.

## Server and upgrade

No database change: 0.17.1 keeps schema 14 and syncs with 0.16.1 desktops and servers.
Update the sync server too to see and delete the server's files in Settings → Files (an
older server works for everything else). Server image:
`ghcr.io/alexanderjacquot/task-master-server:v0.17.1`. The v0.17.0 server image has the
same code; either works.

Installed desktops can update from **Settings → About → Check for updates**.
New installations use the Windows setup executable, macOS DMG, or Linux
AppImage/DEB/RPM. Updates are signed; installers are not platform code-signed.
