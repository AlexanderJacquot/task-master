# task-master 0.16.1

0.16.0 was tagged but never published: its release build stopped at a formatting check.
0.16.1 is the first release with the 0.16.0 changes, listed in
[the 0.16.0 notes](0.16.0.md) (agent timer, Agents page cost, time and spend limits,
multi-select, saved Lineage views, paper sounds), plus the following.

## Calendar

- **Replan a block.** A block's menu now offers Done, Cancelled, **Worked, replan** and
  **Not done, replan** (and Planned, to reset it). The two replan choices then ask where the
  next block goes: **Later today** (the first free time left), **Tomorrow** (or the next
  working day with room), **Pick a time…**, or **Not now** (the task waits in the tray). The
  new block is as long as the old one, and free time follows the working hours set in Plan
  mode.
- **Missed blocks.** "Not done" marks the block *missed*: faded with a dashed edge, no time
  logged, and the task is back to be planned. A missed block leaves Google Calendar, like a
  cancelled one.
- **Daily review.** **Review** in the calendar header shows how many blocks of the last 7
  days ended without an outcome, and goes through them one at a time with the same choices,
  Skip and Open task.

## Quick capture

- The quick-capture window has **rounded corners** (Linux and Windows; macOS keeps square
  corners for now).

## Server and upgrade

**Database change: schema 14** (migration 0014, for the new `missed` outcome; no data
changes). Desktops and sync servers at 0.16.1 use schema 14 and sync only with each other,
so upgrade the sync server together with the desktops. The server image
`ghcr.io/alexanderjacquot/task-master-server:v0.16.1` is published with the release. The
v0.16.0 server image (schema 13) has no matching desktop release; skip it.

Installed desktops can update from **Settings → About → Check for updates**.
New installations use the Windows setup executable, macOS DMG, or Linux
AppImage/DEB/RPM. Updates are signed; installers are not platform code-signed.
