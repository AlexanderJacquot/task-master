# task-master 0.9.0

## Backup and sync frequency

- **Settings → Data and backups → Frequency**: choose how often this device checks its
  backups and retries a failed remote upload (5 minutes to 24 hours, 15 minutes by
  default) and how often it syncs with the server (1 minute to 1 hour, 5 minutes by
  default, or only on changes). Sync still runs shortly after each edit, when the server
  announces changes and when the window gets focus. Saved per device.

## Capture

- **Settings → Adding tasks → Default project**: new tasks created from a page that names
  no project (Today, Upcoming, saved views…) go to the project you pick, instead of the
  Inbox. The Inbox itself keeps adding to the Inbox. Remembered on this computer;
  ignored if that project is archived or deleted.

## Views and search

- The search box of a list or board filters as you type (after a short pause); clearing it
  shows everything again at once.

## Lineage

- New **epic** filter, limited to the epics of the selected project. Tasks added from a
  card keep the epic filter.
- When connecting tasks, the search lists only tasks of the same project unless
  **Include other projects** is checked.

## Sidebar

- Projects in the sidebar are indented under their header.

## Server and upgrade

No database changes: schema stays at **12**, so 0.8.0 and 0.9.0 desktops and servers sync
with each other. The server image `ghcr.io/alexanderjacquot/task-master-server:v0.9.0` is
published as usual; upgrading the server is optional.

Installed desktops can update from **Settings → About → Check for updates**.
New installations use the Windows setup executable, macOS DMG, or Linux
AppImage/DEB/RPM. Updates are signed; installers are not platform code-signed.
