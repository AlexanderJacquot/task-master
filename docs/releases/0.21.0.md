# task-master 0.21.0

## Agents edit your tasks

- Agents can now edit your own tasks through the MCP tools: title, description, priority,
  prerequisites and status, not only their own agent tasks. In a Send to agent session,
  the agent still never marks the session's task done (it goes to Review when the agent
  reports) and never cancels it or its subtasks.
- Settings → Agents → **Let agents edit my tasks** (on by default) turns this off for the
  device. Agents then go back to the earlier rule: status only, and only the session's
  task and its subtasks. It applies to sessions started or resumed after the change.
- Claude Code with the MCP server added by hand follows the same setting's default (on);
  start `task-master-mcp` with `--no-edit-user-tasks` to keep your tasks read-only. The
  remote MCP on the sync server (claude.ai, mobile) also allows edits.

## Compatibility

- No database change (schema 14): syncs with 0.17.1 and later desktops and servers.
- Server image: `ghcr.io/alexanderjacquot/task-master-server:v0.21.0` (its remote MCP now
  allows editing your tasks).
