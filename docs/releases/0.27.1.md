# task-master 0.27.1

0.27.0 was tagged but never published: its release build stopped at a formatting check
(in `progress.md`). 0.27.1 is the same release, with the changes listed in
[the 0.27.0 notes](0.27.0.md): Notes in the sidebar (folders, `[[` task links, notes on task
and project pages, images and files, drag and drop, search in Ctrl/⌘+K, MCP tools for
agents), a lunch break in the day planner, the macOS app named Task Master, and one Dock
icon after an update on macOS.

## Server and upgrade

- **Database schema 19** (0.26.0 was at 17): **update your sync server together with your
  desktops**; they sync only at the same schema. Your data is migrated on first start.
- Server image: `ghcr.io/alexanderjacquot/task-master-server:v0.27.1`. A `v0.27.0` image was
  also published from the unbuilt tag; it has the same code.
