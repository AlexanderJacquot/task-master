# task-master 0.7.1

## Smoother Linux AppImage

- Fixes heavy lag in the parchment theme on the Linux AppImage while dragging tasks or
  typing. The old paper fibre was drawn with fine CSS stripes, which the AppImage's
  bundled WebKit repainted in software on every frame (up to 276 ms per frame); it now
  paints at the speed of a flat background.
- New guidelines and a paint benchmark for backgrounds and effects
  (`docs/rendering-performance.md`, `scripts/paint-bench`).

## Parchment, redrawn

- The parchment theme has a new calfskin texture: warm blotches and fine speckle,
  pre-rendered as an image instead of drawn with CSS.
- **Settings → General → Appearance → Parchment weathering**: add burnt edges, coffee
  rings, water damage or a four-way fold, in any combination. Off by default and
  remembered per computer. Unused layers are never loaded.

## Server and upgrade

No database changes: schema stays at **11**, so 0.7.0 and 0.7.1 desktops and servers sync
with each other. The server image `ghcr.io/alexanderjacquot/task-master-server:v0.7.1` is
published as usual; upgrading the server is optional.

Installed desktops can update from **Settings → About → Check for updates**.
New installations use the Windows setup executable, macOS DMG, or Linux
AppImage/DEB/RPM. Updates are signed; installers are not platform code-signed.
