# task-master 0.22.0

## Scribe: meetings

- Meetings are planned, recorded and transcribed locally (ADR 025, 026): a Scribe tab, a
  meeting page, meetings on the calendar and on task, project and epic pages, attachments
  on meetings, and meetings pushed to Google Calendar (moves are followed back).
- The MCP gains `list_meetings`, `get_meeting` and meetings in `get_calendar`.

## MCP: everything you can do

- Agents can now create, move, delete and undo: `update_task` (project, epic, parent, due,
  today, estimate, owner, tags, position), `delete_task`, project/epic/tag edits and
  deletes, attachments, `remove_agent_session`, and `undo` by the `change_id` every write
  reports. Calendar blocks and links follow **Let agents edit my tasks**.
- Windows: the installer now stops a running `task-master-mcp.exe` so updates can replace it.

## Compatibility

- Database schema 15 (meetings): update desktops and the sync server together.
- Server image: `ghcr.io/alexanderjacquot/task-master-server:v0.22.0`.
