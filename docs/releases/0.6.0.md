# task-master 0.6.0

Connect tasks with dependencies, see how they flow in the new Lineage view, and send due
dates to Google Calendar.

- **Lineage:** add prerequisites and dependents to a task, and see chains, branches and
  joins on a graph (sidebar → Lineage). Cycles are refused, and every change can be undone.
- **Calendar deadlines:** due dates appear as all-day "Due: …" events in the task-master
  calendar. Moving one in Google Calendar changes the due date, and deleting it clears
  the due date.
- **Epic colors and shapes:** pick each epic's color and shape on its page. They show in
  the sidebar, on board cards and in the epic selector.
- **Date picker:** a new calendar picker for due and plan dates in task rows, the task
  panel and epics.
- **Tag picker:** redesigned to match the other menus.
- **Search in All tasks:** search titles and descriptions next to the creation row, in
  list and board views.
- **Quick capture:** delete a task right from the expanded capture popup.
- **Sync sign-in:** clicking Sign in again (or Start over) replaces a sign-in that is still
  waiting, instead of failing with "port 47823 is busy". Syncing continues while you sign in.
- Polish: rubric drop caps in sidebar descriptions, visible board column resize handles,
  and larger calendar dates.

**Update the server and every desktop to 0.6.0 together.** This release adds database
migrations, and a 0.6.0 desktop cannot sync with a 0.5.0 server (or the other way round).
The server image is now `ghcr.io/alexanderjacquot/task-master-server` (ADR 016). Server
setup: [server guide](../server.md). Local databases migrate automatically.
