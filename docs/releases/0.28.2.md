# task-master 0.28.2

0.28.0 and 0.28.1 were tagged but never published: their release builds stopped in the
Linux tests, unable to link sherpa-onnx (CI's Rust cache kept the folder of its downloaded
libraries but not the libraries). 0.28.2 is the same release, with the changes listed in
[the 0.28.0 notes](0.28.0.md): team spaces (a shared space with assignees, comments,
mentions and "For you", for a sync server with `TM_TEAM=on`), roadmap images from the app
and from the sync server, taking a bar off the roadmap, double-click to open a bar, Notes
higher in the sidebar, and Task Master as the name on Macs updated from `task-master.app`.

## Server and upgrade

- **Database schema 22** (0.27 was at 19): **update your sync server together with your
  desktops**; they sync only at the same schema. Your data is migrated on first start.
- Server image: `ghcr.io/alexanderjacquot/task-master-server:v0.28.2`. `v0.28.0` and
  `v0.28.1` images were also published from the unbuilt tags; they have the same code.

## For contributors

- CI and release jobs download sherpa-onnx again when the Rust cache restored its folder
  without the library.
