# task-master 0.25.0

Back to the desktop app's conversation in one click, a foldable Projects section, and a
fix for agent folders when sessions sync from several computers.

## Agents

- **Click "In desktop app"** on a session (the task's sessions or the Agents page) to go
  back to its conversation in the Claude desktop app (macOS and Windows). It is found
  by the conversation the session recorded, or else by its first prompt. When it cannot
  open, the card or row says why: the prompt was not sent yet, the conversation was
  deleted or archived there, or the session was opened on another computer.
- **Fix:** Send to agent prefilled the task's last folder, and offered recent folders,
  from sessions run on other computers (sessions sync), so a start on macOS could get a
  Linux path and fail with "the folder … does not exist". It now only takes folders of
  this computer's sessions.

## Sidebar

- The **Projects** header folds its section like **Epics**: open by default, remembered
  on this computer. **New project** unfolds it.

## For contributors

- devenv now provides `cmake` on every platform, and `.envrc` loads it on macOS too; a
  SessionStart hook gives Claude Code's shell the devenv tools (cargo, cmake, pnpm).

## Compatibility

- Database schema 17, as in 0.24.0: no migration, and a 0.24 sync server keeps working.
- Server image: `ghcr.io/alexanderjacquot/task-master-server:v0.25.0`.
