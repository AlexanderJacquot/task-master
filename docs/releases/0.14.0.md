# task-master 0.14.0

## Appearance

- **A Clean theme.** Settings → Appearance now offers **Clean** beside Dark and Parchment:
  a plain, Notion-like light look for when the illuminated style is not what you want.
  - White pages, a soft grey sidebar, charcoal text and one blue accent for actions.
  - Inter for all text (bundled, so it looks the same on every computer), with semibold
    titles instead of the display lettering.
  - Simple line icons everywhere, including project icons (drawn in the project's color),
    and a plain logo.
  - No parchment texture, dividers, wax seals or drop caps; board columns and the full
    task page are borderless; Metrics uses plain names ("Created", "Burn-down").
- **Follow the system** can now pick its light theme: Parchment or Clean. Dark mode stays
  the dark theme.

## Calendar

- **Filter the task list.** The project, epic and status choices moved from the Plan bar
  into the task list beside the calendar, as a **Filter** that works in every mode, with
  **Clear filter**. Planning still draws from the same filter.
- **Resize the task list** by dragging its right edge (double-click to reset). Remembered
  on this computer.

## Updates

- **The Update pill works in one click.** "Update to X" in the sidebar now downloads the
  update and shows its progress, then becomes "Restart to use X"; it also opens
  Settings → About. Before, it only opened Settings.

## Server and upgrade

No database changes: schema stays at **12**, so 0.8.0 to 0.14.0 desktops and servers sync
with each other. The server image `ghcr.io/alexanderjacquot/task-master-server:v0.14.0`
is published as usual; upgrading the server is optional.

Installed desktops can update from **Settings → About → Check for updates**.
New installations use the Windows setup executable, macOS DMG, or Linux
AppImage/DEB/RPM. Updates are signed; installers are not platform code-signed.
