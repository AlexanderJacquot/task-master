# task-master 0.12.0

## Board

- **Collapsible swimlanes.** With swimlanes on, click a lane's title to fold it. A folded
  lane shows its card count and a low strip under each column; drop a card on a strip to
  put it on top of that cell. Folded lanes are remembered on this computer, per epic,
  project or tag, so an epic stays folded on every board.
- **Hold to open.** While dragging, hold a card over a folded lane for a second and it
  opens until you drop, so you can place the card among the lane's cards. It folds again
  afterwards.

## Calendar

- **Resize from both edges.** Time blocks in the day and week grids now resize from their
  top edge (start) as well as their bottom edge (end), on quarter hours and never shorter
  than 15 minutes. The handles show a grip on hover, and the block shows its new range and
  length while you drag. Very short blocks keep only the bottom handle so they can still
  be moved.
- Releasing a resize no longer opens the block's menu.
- **Shift+↑ / Shift+↓** on a focused block shortens or lengthens it by 15 minutes.

## Epics

- Click the epic's mark beside its name to pick its **color and shape**, like a project's
  icon. This replaces the two menus in the details row.

## Server and upgrade

No database changes: schema stays at **12**, so 0.8.0 to 0.12.0 desktops and servers sync
with each other. The server image `ghcr.io/alexanderjacquot/task-master-server:v0.12.0`
is published as usual; upgrading the server is optional.

Installed desktops can update from **Settings → About → Check for updates**.
New installations use the Windows setup executable, macOS DMG, or Linux
AppImage/DEB/RPM. Updates are signed; installers are not platform code-signed.
