# task-master 0.31.1

Scribe fixes: much faster transcription on Windows and playback that works, plus in-app
updates for every platform.

**Database schema 23**, as in 0.29 and 0.30: no migration. Keep your sync server on the
same version as your desktops all the same.

## Scribe

- **Transcription on Windows is many times faster.** The Windows build compiled the
  speech engine (whisper.cpp) without optimization and with its debug checks on: the
  build tools dropped the usual optimization flags. large-v3-turbo took 847 s for 33 s of
  speech. With the flags put back, one encoder pass went from 41.6 s to 2.7 s (15×) on a
  6-core Ryzen 5 5500. macOS and Linux builds are unchanged. Found and fixed by
  samuelld85-blip (GitHub issue #1).
- **Recordings play again, on every OS.** The player's address had its path
  percent-encoded and the app did not decode it, so it answered "not found" and the player
  said the file was refused or its format was not supported.
- **More in `scribe.log`.** A `machine:` line names the processor, cores and threads,
  battery or power, and the Windows power mode. `window:` lines note when the main window
  goes to the background, is minimized or hidden. Short recordings show seconds instead of
  "1 min".

## Updates

- **Apple Silicon Macs and Linux get updates again.** 0.31.0's update manifest
  (`latest.json`) listed only Intel Macs and Windows: the build jobs overwrote each
  other's entries. A last step now writes it once from every build. Installed 0.30.x apps
  on those platforms go straight to 0.31.1.

## For contributors

- `.cargo/whisper-msvc.cmake` restores CMake's Release flags under MSVC; `.cargo/config.toml`
  hands it to whisper-rs-sys as `CMAKE_PROJECT_INCLUDE`.
- `scripts/updater-json.mjs` (with tests) builds `latest.json` in the new `updater-json`
  job, which fails if a platform is missing.
- devenv shares `~/.cargo` across checkouts, so sccache hits across worktrees.
- Not yet checked: the Windows fix was measured on a local build, not yet on the release
  runner; the playback fix has a test but has not been tried in the running app; this is
  the first release to run the `updater-json` job.
