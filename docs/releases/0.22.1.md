# task-master 0.22.1

## Fixes

- **Terminals after an in-app update.** An app restarted by the updater passed the old
  AppImage's library paths on to agent terminals, so kitty crashed on start
  (`undefined symbol: cairo_font_options_set_color_palette`). Paths from any earlier
  AppImage mount are now left out too.
- **Command palette** no longer lists done tasks.
- **Board cards** shorten long tags instead of growing wider.
- **Sidebar** groups indent their items.

## Compatibility

- No database change (schema 15, as in 0.22.0).
- Server image: `ghcr.io/alexanderjacquot/task-master-server:v0.22.1`.

Installed desktops can update from **Settings → About → Check for updates**.
New installations use the Windows setup executable, macOS DMG, or Linux
AppImage/DEB/RPM. Updates are signed; installers are not platform code-signed.
