# task-master 0.20.0

## Remote MCP (sync server)

- The sync server can serve the task-master MCP tools at `POST /mcp` for claude.ai and the
  mobile apps, when started with `TM_MCP=on` (off by default). Claude's writes are
  announced on `/events`, so desktops pull them at once.
- The server acts as an OAuth resource server for Authelia: it publishes RFC 9728
  metadata and checks RFC 9068 access tokens (issuer, audience `<public>/mcp`, expiry,
  allowed clients and groups). Server tokens need `api:write`. Setup: docs/mcp.md
  section 5; design: ADR 024.
- Not yet tried against a real Authelia and claude.ai.

## MCP tools

- `create_project` (in an area or top level) and `create_epic` (with project,
  description and target date; in an agent session, the session task's project by
  default). What they create is the user's. Asking for one that already exists, by name
  in the same place, returns it instead of a duplicate.

## Sync server

- Sync routes check the token before reading the request body, so the server can be
  exposed publicly without anonymous uploads (up to 64 MB) being buffered.

## Compatibility

- No database change (schema 14): syncs with 0.17.1 and later desktops and servers.
- Server image: `ghcr.io/alexanderjacquot/task-master-server:v0.20.0`.
