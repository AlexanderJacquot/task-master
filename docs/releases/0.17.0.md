# task-master 0.17.0

## Files

- **Settings → Files** lists the attached files on this device and on the sync server, with
  storage totals, filters by age and size, sorting, the tasks each file is attached to, and
  a cleanup of unused files. Pick several files and delete them for good (with a
  confirmation): their attachments go in one undoable step, the content is removed here and
  on the server, and other devices drop their copies on the next sync. Backups keep theirs.

## Agents

- **Claude plan usage** on the Agents page: the 5-hour window and the weekly windows, each
  with what is left and when it resets, like `/usage` in Claude Code. Read from the Claude
  Code sign-in where agents run; refreshed every 5 minutes and with Refresh.
- **Recent sessions by day**: "Today", "Yesterday", "Monday, Nov 9", each with the day's
  session count and cost. Every session shows its task's project and epic.
- **MCP**: `list_agent_sessions` filters by state, task and project, can keep only each
  task's latest run (for example, tasks whose latest run failed), and pages through results.
  `list_tasks` pages too when it hits its 200-row limit.

## Calendar

- **3 days**: a range of today and the next two days, next to Day, Week and Month.
- **Filter by several values**: the tray filter (also the Plan focus) picks several
  projects, epics and statuses, with "Inbox" and "No epic".

## List, board and Lineage

- **Reset view** in the Display popover (list and board, built-in and saved views): back to
  the default filters, grouping, sort and toggles, clears the search, folded groups and
  selection; on the board, columns share the width equally again.
- **Drag a multi-selection** on the board: every picked card moves together, onto another
  column or lane, or onto a project, epic or Today in the sidebar.
- **Lineage lanes by epic** show only epics with cards in view. Pick an epic in the Epic
  filter to get its empty lane and drop cards into it.

## Server and upgrade

No database change: 0.17.0 keeps schema 14 and syncs with 0.16.1 desktops and servers.
Update the sync server too to see and delete the server's files in Settings → Files (an
older server works for everything else). Server image:
`ghcr.io/alexanderjacquot/task-master-server:v0.17.0`.

Installed desktops can update from **Settings → About → Check for updates**.
New installations use the Windows setup executable, macOS DMG, or Linux
AppImage/DEB/RPM. Updates are signed; installers are not platform code-signed.
