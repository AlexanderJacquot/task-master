# task-master 0.15.0

## Tasks

- **Work timer.** "Start timer" on the task page and in the side panel (Time row). One
  timer runs per computer; starting it moves a to-do or backlog task to in progress.
  - A pill at the bottom of the sidebar shows the running task and its clock; click it to
    open the task or stop the timer.
  - Stopping logs the run as worked time on the calendar (runs under a minute are dropped),
    in one undoable step. The task shows the time logged against its estimate.
  - Starting on another task stops and logs the one that was running.
- **Fold the description.** The Description section of the side panel and the full task
  page has a header that folds it; folded, it shows the description's first line. The
  choice is remembered on this computer, separately for the panel and the page. A task you
  just created always opens with its description visible.
- **Subtasks all the way down.** The list nests subtasks at any depth (it used to stop at
  two levels). Rows with subtasks have a chevron; top-level rows start unrolled. "Show
  subtasks" in Display now works in list mode too and unrolls every level.
- **Clicking a subtask on the full task page** opens that subtask's page (it did nothing).

## Board and Lineage

- **Add a task from a swimlane.** A "+" by each swimlane's name adds tasks straight into
  that lane (its epic, project or priority). The field stays open for the next one.
- **Lineage side panel readable.** Search results show the title on its own line with the
  link buttons below it, and the panel is wider.

## Claude

- **Agent directive.** Settings → Agents has a *Directive* box: standing instructions
  added to every Claude session this computer starts.
- **task-master in your own Claude.** The `task-master-mcp` server finds the app's database
  by itself, so `claude mcp add task-master -- <path to task-master-mcp>` is enough; see
  [docs/mcp.md](../mcp.md) for Claude Code and Claude Desktop on each OS. Your own tasks
  are read-only there.
- **Calendar and lineage tools** for agents: read the calendar, plan and update time
  blocks, see a task's prerequisite chains and what is ready, and link prerequisites.

## Settings and fixes

- The default project for new tasks uses the app's own dropdown, with project colors.
- The quick-capture window follows the theme after you change it in Settings (it kept the
  parchment look).

## Server and upgrade

No database changes: schema stays at **12**, so 0.8.0 to 0.15.0 desktops and servers sync
with each other. The server image `ghcr.io/alexanderjacquot/task-master-server:v0.15.0`
is published as usual; upgrading the server is optional.

Installed desktops can update from **Settings → About → Check for updates**.
New installations use the Windows setup executable, macOS DMG, or Linux
AppImage/DEB/RPM. Updates are signed; installers are not platform code-signed.
