# task-master 0.29.0

A new look: clean light and dark themes by default, a new logo, and the medieval look kept
as an option. Also CalDAV calendars (iCloud, Fastmail, Nextcloud), "Show as" and privacy
for meetings, epics that stay with their project, and a fix for Outlook blocks that came
back as events.

**Database schema 23** (0.28 was at 22): update your sync server together with your
desktops; they sync only at the same schema.

## A new look

- **Clean by default.** The app now opens in the clean light theme. Settings → Appearance
  offers **Light**, **Dark** and **Follow the system**.
- **A new dark theme** in the same clean style: soft charcoal, warm off-white text and the
  same blue accent, instead of the candlelit one.
- **The medieval look stays, as an option.** Tick **Illuminated manuscript** in Settings →
  Appearance: parchment in light mode, candlelight in dark mode, with weathering and paper
  sounds. If you chose Parchment before, you keep it; the old Dark becomes the new clean
  dark.
- **A new logo and app icon**: the stack of stones, redrawn as a stack of tasks.
- Roadmap images exported from the dark theme use its colors (`theme=clean_dark` on the
  sync server).
- The README and the project website follow the new look.

## Calendar

- **CalDAV accounts**: connect iCloud, Fastmail, Nextcloud or any CalDAV server in
  Settings → Calendar → **iCloud & CalDAV**, as a third choice beside Google and Outlook.
  Your blocks, day plans and due dates go to its calendar, its events show in yours, and
  recurring events are expanded. The password (an app password for iCloud) stays in your
  system's keychain. The sync server can run a CalDAV account too (docs/caldav.md).
- **Show as and privacy for meetings**: a meeting shows as busy, tentative or free, and
  private or visible, set on the meeting's page. Google, Outlook and CalDAV receive it, and
  a change made in Google or Outlook comes back. The calendar draws tentative items with
  a broken edge, free ones lighter and private ones with a padlock.
- **Outlook**: a task dragged onto the calendar no longer shows a second time as an Outlook
  event. Each sync now writes one line (counts and errors, no titles) to `calendar.log` in
  the data folder.

## Epics

- **Epics stay with their project**: a project's epics are offered only for that project's
  tasks (and its area's); loose epics go anywhere. The sidebar's Epics section groups them
  by project, in folders that remember whether they are open.

## Windows

- The MCP server's executable now carries version information. Code signing through
  SignPath is prepared but stays off until the project is approved: installers are still
  unsigned.

## For contributors

- ADR 036 (Windows code signing), ADR 037 (CalDAV), ADR 038 (meeting show-as and privacy),
  ADR 039 (clean by default). Migration 23 (meeting and event show-as and privacy).
- New dependencies: `rrule` 0.14 and `keyring` 4.2 (CalDAV), `tauri-winres` 0.3 (Windows
  version resource). The Windows release job now builds, bundles and signs in steps.
- Not tried yet against a real CalDAV server, nor against Outlook for the duplicate fix.
  The new Windows release steps run for the first time in this release.
