# task-master 0.18.0

## Timers

- **Several timers at once**: each task has its own timer, and starting one no longer stops
  the others. The sidebar shows one row per running timer, each with its own Stop. A timer
  running from an earlier version carries over.

## Agents and projects

- **Git state of a project folder**: the project page shows the folder's release (latest
  tag and commits since) and branch beside the folder button, with the commit and
  uncommitted changes in its menu. Read with the system's git where agents run, WSL
  included; nothing shows when the folder is not a repository.

## Tasks

- **Quick capture**: Ctrl+Enter (Cmd+Enter) saves the field being edited and closes the
  expanded editor.
- **Copy the task id** from the task panel and the task page, for MCP calls and agents.

## Settings

- **Files** shows a thumbnail for images on this device and a file-type icon otherwise.
- **Sync now** (sync and Google Calendar) and **Back up now** show a spinner while working.

## Lineage

- A tighter header leaves more room for the canvas.

## Server and upgrade

No database change: 0.18.0 keeps schema 14 and syncs with 0.17.1 desktops and servers.
Server image: `ghcr.io/alexanderjacquot/task-master-server:v0.18.0`.

Installed desktops can update from **Settings → About → Check for updates**.
New installations use the Windows setup executable, macOS DMG, or Linux
AppImage/DEB/RPM. Updates are signed; installers are not platform code-signed.
