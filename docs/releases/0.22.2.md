# task-master 0.22.2

macOS fixes.

## Fixes

- **macOS: the app opens after downloading.** Release builds are now ad-hoc signed as a
  whole bundle, MCP server included, so macOS no longer calls the downloaded app
  "damaged". The first open still asks once: System Settings → Privacy & Security →
  *Open Anyway*. A Developer ID signature, which would remove that step, comes later.
- **macOS: quick capture over everything.** `Ctrl+Shift+Space` opens the capture box over
  full-screen apps and on every desktop Space without switching away from what you were
  doing, the way Spotlight does.
- **Dropping files in quick capture.** Files dragged onto the capture editor's attachments
  or description are now added (they were ignored on every system).
- **macOS: dropping files lands where you drop them.** On Retina screens a dropped file
  went to the element at half the pointer's position; drops now hit what is under the
  pointer, in the main window too.
- **macOS: the window's top is flush.** The grey system title bar is gone: the app's colors
  reach the top edge, with the traffic lights on the app's own strip, as on Windows and
  Linux.

## For developers

- `devenv.nix` provides the pinned Rust toolchain, Node 24 and pnpm, with every cache kept
  in `.devenv/` inside the checkout (README → Build from source).
- New workspace crate `crates/macos-panel`, the only one that allows unsafe code (ADR 027).

## Compatibility

- No database change (schema 15, as in 0.22.0).
- Server image: `ghcr.io/alexanderjacquot/task-master-server:v0.22.2`.

Installed desktops can update from **Settings → About → Check for updates**.
New installations use the Windows setup executable, macOS DMG, or Linux
AppImage/DEB/RPM. Updates are signed; installers are not platform code-signed.
