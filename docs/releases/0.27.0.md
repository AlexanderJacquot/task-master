# task-master 0.27.0

Notes: markdown pages in the sidebar, in folders, linked to your tasks and projects, which
you and your agents can search, write and fill with images. Also a lunch break in the day
planner, and on macOS the app is now called Task Master.

## Notes

- **A Notes section in the sidebar**: markdown pages in simple folders. **+** writes one; a
  folder's **+** or **⋯** writes one in it; double-click renames a folder. Deleting a folder
  keeps its notes (they move out of it).
- **A note's page**: a large title, then the text, rendered until you click it. Its bar
  moves the note to a folder, attaches it to a task, or deletes it (Ctrl/⌘+Z brings it
  back).
- **Link tasks as you write**: type `[[` in a note, a task description or meeting notes to
  search your tasks; the one you pick becomes a link that shows the task and opens it.
- **Notes on tasks and projects**: a task's panel and page list the notes attached to it,
  then those that link to it, with **New note**. A project's page lists the notes that link
  it or one of its tasks; its **New note** (also in the project's ⋯ menu) starts one with a
  link to the project.
- **Images and files**: paste or drop them into a note, as in a task description. They are
  listed under the text, and Settings → Files shows which note holds a file.
- **Drag and drop**: drag a note onto a folder, next to another note, or onto "Drop here for
  no folder".
- **Search**: Ctrl/⌘+K finds notes by title, or by any words in them (with the words around
  the match), and has a **New note** action.
- **For agents** (the task-master MCP server): `list_notes`, `get_note`, `create_note`,
  `update_note` and `delete_note`, attachments on notes, and notes in `search` results.
  Agents may always write a new note; changing yours follows Settings → Agents → *Let
  agents edit my tasks*.

## Calendar

- **Lunch break in the day planner**: Plan mode's bar has a **Lunch** checkbox with a start
  time and a length. Suggest, the free-time summary and "Later today" keep it free. It is
  off by default and remembered on this computer.

## macOS

- **The app is called Task Master** in the Dock and Finder. A new install from
  the .dmg is `Task Master.app`; an app updated from Settings → About stays where it is
  (`task-master.app`) and only changes its displayed name, so an MCP path set up by hand
  keeps working.
- **Fix: one Dock icon after an update.** The app used to come back next to its own pinned
  icon. This fix runs from the *next* update on: the restart into 0.27.0 is still made by
  0.26.0's code.
- The search boxes of Ctrl/⌘+K and the `[[` task search no longer show macOS's text
  prediction over the first result.

## For contributors

- ADR 032 (notes). Migrations 18 (notes, folders) and 19 (note search, files on notes).

## Compatibility

- **Database schema 19** (0.26.0 was at 17): **update your sync server together with your
  desktops**. A desktop syncs only with a server at the same schema, so a 0.26 app and a
  0.27 server (or the other way round) stop syncing until both are updated. Your data is
  migrated on first start; keep a backup if you want to be able to go back to 0.26.
- Server image: `ghcr.io/alexanderjacquot/task-master-server:v0.27.0`.
