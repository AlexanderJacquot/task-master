# task-master 0.10.0

## Lineage

- **Side panel**, always available (hide or show it; remembered): **Search tasks** finds
  any task in any project. Picking a result selects its card and centers it, or opens its
  lineage when the filters hide it. With a task selected, each result offers **+ Prereq**,
  **+ Dependent**, **+ Parent** and **+ Subtask**, and the search text can be created as a
  new prerequisite or dependent. Replaces the "Connection type" select and the "Include
  other projects" box.
- **Dependents follow this task**: copies the selected task's project, epic and tags onto
  its dependents, or the whole chain downstream, in one undoable step. Tags are added,
  never removed. Tasks created from a card's plus buttons also take the card's tags.
- The selected task shows "Subtask of …", with a button to make it top-level.
- A plus button's popover closes on any click elsewhere on the canvas, even with text typed.
- Cards stay sharp at every zoom level on Linux (they looked blurry before).
- Opening a task's lineage frames its cards, and the task always shows even when the saved
  filters would hide it.

## Subtasks

- Task details: **Make it a subtask of…** (or **Move under another task…**), and
  **Add an existing task…** under the subtask list. Both open a searchable picker that
  leaves out choices that would create a loop. Subtasks move with their parent's project
  and epic.

## Filters

- The Epic and Tags filters list **No epic** and **No tag** first. They combine with other
  choices ("any of") and are kept in saved views.

## Metrics

- Figures with medieval titles and the plain measure underneath.
- **Burn-down**: open tasks at the end of each day of the period, with the net burn rate,
  a projected clear date and a hover crosshair. The daily table gets "Open at day end".
- **Focus on one project or tag**: from the Project picker, a "By project" or "By tag" row,
  or the sidebar project menu → Metrics. A banner offers "Show all projects".

## Look

- New purple app icon and a banner logo in the sidebar. Divider under page titles and a
  wax seal on empty pages.
- Board cards show the epic label in the epic's color.

## Server and upgrade

No database changes: schema stays at **12**, so 0.8.0, 0.9.0 and 0.10.0 desktops and
servers sync with each other. The server image
`ghcr.io/alexanderjacquot/task-master-server:v0.10.0` is published as usual; upgrading the
server is optional.

Installed desktops can update from **Settings → About → Check for updates**.
New installations use the Windows setup executable, macOS DMG, or Linux
AppImage/DEB/RPM. Updates are signed; installers are not platform code-signed.
