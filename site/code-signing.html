Code signing policy

Effective date: 22 November 2026

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

1. What is signed

The Windows files of each task-master release are signed: the app (taskmaster-desktop.exe), its MCP server (task-master-mcp.exe), the setup .exe and the .msi. Windows shows SignPath Foundation as their publisher.

They are built from the public source code by the project's release workflow on GitHub-hosted runners, from a version tag. Nothing built elsewhere, including on a maintainer's computer, is signed. Third-party libraries built into the app keep their own open-source licenses.

2. Team roles

Committers and reviewers
Alexander Jacquot. Changes from anyone else are reviewed by him before they are merged.
Approvers
Alexander Jacquot. Every signing request is approved by hand in SignPath.

Team members use multi-factor authentication on GitHub and SignPath.

3. Privacy

The app stores your tasks on your device. It contacts GitHub to check for updates. It contacts other services only when you use them: your own sync server, Google Calendar, backup storage, Hugging Face to download transcription models, and Anthropic with your own Claude login to show your Claude plan usage. The privacy policy has the details.

4. Reporting a problem

If you find a signed file that was not built this way, or have a question about this policy, open an issue on the project support page.
